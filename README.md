# ZLWH Gallery

独立静态图集，包含 14 张图片，按原比例瀑布流展示，支持图片放大、左右切换、全屏和 Esc 关闭。无需安装依赖或运行构建。

## 本地查看

双击 index.html 即可打开。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个仓库，例如 gallery。
2. 将本目录内的 index.html、style.css、gallery.js、images 文件夹和 .nojekyll 上传到仓库根目录。不要再套一层 Gallery 文件夹。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，点击 Save。
5. 等待部署完成，访问 Pages 设置中显示的网址。若账号为 FaaaQwQ、仓库名为 gallery，地址通常为 https://faaaqwq.github.io/gallery/。

## 更新图片

替换 images 中对应图片并提交即可更新。添加或减少图片时，同时更新 gallery.js 中的 photos 图片路径列表。
